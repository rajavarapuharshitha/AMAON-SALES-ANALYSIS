# 📊 Amazon Sales Analysis Dashboard

This project is a comprehensive and interactive **Power BI Dashboard** designed to analyze Amazon sales performance, evaluate key metrics, and provide valuable business insights.

---

## 🚀 Key Performance Indicators (KPIs)
- **Total Sales:** 78.59M
- **Total Quantity Sold:** 117K

---

## 📈 Dashboard Visualizations & Insights
1. **Sales by Category:** Visual breakdown showcasing top-performing product categories like *Set*, *Kurta*, *Western Dress*, *Top*, and *Ethnic Dress*.
2. **Sales by Shipping City:** Highlights top delivery locations including *Bengaluru*, *Hyderabad*, *Mumbai*, *New Delhi*, and *Chennai*.
3. **B2B Sales:** Analysis of business-to-business transactions versus individual consumer sales.
4. **Sales by Channel:** Channel-wise performance tracking.
5. **Sales by Date:** Trend analysis displaying sales performance over time.
6. **Quality by Ordered Status:** Order status distribution indicating shipping, cancellation, and return metrics.

---

## 🛠️ Tools & Technologies Used
- **Power BI Desktop:** Data modeling, DAX, and interactive data visualization.
- **GitHub:** Version control and project hosting.
